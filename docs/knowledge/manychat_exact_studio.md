## 🎨 O que mudou (Fidelidade Pixel-Perfect ao ManyChat):

1. **Clean Light Mode Canvas:** Fundo suave `#F8FAFC` com grid pontilhado suave de 20px.
2. **Cards de Nós Brancos (Nodes):**
   - Sombras suaves, topo colorido por tipo (Laranja para *Trigger*, Azul para *Condition/Follow-Gate*, Verde para *Send Message*).
   - Botões estilo Quick Reply dentro do card com borda e texto azuis (`#0084FF`).
3. **Linhas Curvas de Conexão Azuis e Verdes:**
   - SVG com curvas Bézier perfeitas conectando os pontos de saída e entrada.
   - Bolinhas de conexão azuis com borda branca nas laterais dos cards (*Out-Right / In-Left Ports*).
4. **Barra Lateral Esquerda ManyChat:**
   - Slate escuro `#1C2536` com ícone original do logo `MC`, navegação para *Automation*, *Triggers*, *Follow Gate*, *Contacts CRM* e *Content Catalog*.
5. **Breadcrumbs e Header Superior:**
   - Barra branca superior com breadcrumbs de navegação (*Automation / Flows / Instagram Follow-Gate*), tag verde de status `Zernio Live Connected` e botão principal azul `Publish Workflow`.
