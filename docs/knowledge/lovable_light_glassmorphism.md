# 💎 PROMPT LOVABLE: LIGHT MODE GLASSMORPHISM CONCEITUAL (ESTILO APPLE VISION OS / STRIPE)

> **Proposta Visual:**
> - Fundo claro, limpo e orgânico com gradientes suaves (Mesh Gradient) em tons de azul pastel, violeta suave e pérola.
> - Placas de vidro fosco translúcido (*frosted glass / backdrop-blur*) flutuantes com sombras suaves e bordas brancas sutis (`border white/40`, `shadow-xl`, `backdrop-blur-md`).
> - Visual conceitual de alta tecnologia, limpo, leve, elegante e fácil de ler.

---

### 📝 Copie e cole este prompt no chat do seu projeto no Lovable:

```text
Completely transform the visual theme of the application into a Light-Mode Conceptual Glassmorphism design (inspired by Apple VisionOS, Stripe, and iOS light glass aesthetics).

1. Background & Atmosphere:
- Remove all dark background colors!
- Use a light, luminous, organic mesh gradient background with ultra-soft pastel tones (frosted pearl #F8FAFC, soft ice blue #E0F2FE, and gentle lavender aura #F3E8FF).
- The background should feel airy, premium, and alive with subtle ambient gradients.

2. Glassmorphism Card System:
- All cards, code blocks, and containers must be styled as floating frosted glass panels (backdrop-filter: blur(20px)).
- Card Background: Translucent pure white (rgba(255, 255, 255, 0.65) or bg-white/70).
- Card Borders: Extremely fine, glowing white/light borders (1px solid rgba(255, 255, 255, 0.8) or border-white/60).
- Card Shadows: Multi-layered, soft ambient drop shadows (box-shadow: 0 20px 40px -15px rgba(0, 0, 0, 0.05), 0 0 15px rgba(255, 255, 255, 0.5)).

3. Typography & Color Palette:
- Headings: Deep indigo navy (#0F172A / #1E1B4B) with a subtle frosted sheen.
- Subtitles & Body: Refined slate gray (#475569).
- Accents & Highlights: Radiant royal blue (#2563EB) and soft electric indigo (#4F46E5).
- Variables inside Prompts (e.g., {{NOME_DA_EMPRESA}}): Styled as soft pastel blue pill badges (bg-blue-100/80 text-blue-700 border border-blue-200/50).

4. Component Redesign:

- Category Pills (Filtros):
  - Inactive: Frosted translucent white pill (bg-white/50 text-slate-600 border border-slate-200/60 blur backdrop).
  - Active: Vibrant electric blue fill (#2563EB) with white text, soft blue glow shadow.

- Code Block / System Prompt Card:
  - Container: Light frosted glass IDE panel with a clean top bar and smooth rounded corners.
  - Code Text: Deep slate dark text (#0F172A) on a ultra-clean light frosted background (bg-white/80), with vivid indigo and teal syntax highlighting.
  - "Copy Prompt" Button: Frosted white glass button with blue icon and hover animation.

- Input Fields (Variáveis):
  - Crisp light frosted input (bg-white/80 text-slate-900 border border-slate-300/60 rounded-xl).
  - High-contrast text with a bright blue focus ring.

- Buttons & CTAs:
  - Primary Buttons: Vibrant royal blue gradient (#2563EB to #3B82F6) with soft depth shadow and white text.
  - Secondary Buttons: Floating glass pill button (bg-white/80 text-slate-800 border border-white).

Make the entire UI feel luminous, lightweight, conceptual, futuristic yet clean, floating, and beautifully frosted!
```

### 🎨 O que muda com esse design:
- ☀️ **Fundo Claro Luminoso:** Tons de pérola, gelo e lavanda suave em degradê orgânico.
- 🪟 **Efeito Vidro Fosco (*Glassmorphism*):** Cartões brancos semi-transparentes que parecem flutuar sobre o fundo com desfoque (*blur*).
- 💎 **Visual Conceitual Estilo Apple VisionOS / Stripe:** Esqueça o visual "trevoso" de hacker; fica super sofisticado, limpo e conceitual!
