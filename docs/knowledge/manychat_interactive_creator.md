Entendi perfeitamente! Você precisa de um **criador interativo** onde pode escrever novos textos, adicionar novos blocos, configurar novos botões e criar os próximos fluxos da sua automação para o futuro!

## ⚡ Como funciona o novo Criador Interativo:

1. **Inspector Lateral Direito de Edição (Inspector Panel):**
   - Selecione qualquer bloco no canvas e edite o **Título**, o **Texto da Mensagem no Instagram** e o **Tipo de Bloco** em tempo real.
   - Veja o bloco no canvas atualizar instantaneamente conforme você digita!

2. **Criador de Novos Botões & CTAs:**
   - Botão **`＋ Adicionar Novo Botão`** no inspector lateral: crie quantos botões de resposta/redirecionamento quiser para o novo bloco.

3. **Criador de Novos Blocos (`＋ Criar Novo Bloco`):**
   - Adicione novos blocos no canvas para expandir a conversa para frente.

4. **Publicação Direta (`Publicar no Instagram`):**
   - Botão azul no topo superior direito para publicar as novas alterações do fluxo.
