# 🎨 PROMPT REVISADO (DESIGN APPLE/DARK CYBERPUNK SLEEK) PARA O LOVABLE

> **O que mudamos no design:**  
> 1. **Fim do Roxo/Rosa Genérico:** Substituído por um tema **Dark Onyx / Matte Charcoal** (#0B0F17) com acentos elegantes em **Azul Elétrico / Ciano Minimalista (#00E5FF / #3B82F6)**.
> 2. **Tipografia & Legibilidade:** Texto principal em **Branco Puro / Zinco Claro (#F8FAFC)**, removendo textos apagados difíceis de ler.
> 3. **Cards & Vidro (Glassmorphism):** Bordas finas com brilho sutil (`border-slate-800`, `bg-slate-900/60`), cantos ligeiramente arredondados (`rounded-xl`), sem neon agressivo ou caótico.
> 4. **Botões Limpos:** Botões principais com gradiente suave e bordas bem definidas, sem botão roxo chocante de IA amadora.

```text
Refactor the design and color palette of the entire application to feel ultra-premium, dark, sleek, and minimalist (inspired by Apple, Linear.app, and Vercel dark mode).

Color Palette Redesign:
- Background: Deep Matte Charcoal / Onyx (#090D16).
- Card Surfaces: Dark translucent glassmorphism (#111827 / rgba(17, 24, 39, 0.7)) with crisp 1px subtle borders (#1F2937 or #374151).
- Primary Accents: Electric Cyan / Modern Tech Blue (#00E5FF and #3B82F6). Remove all bright violet, pink, or overly saturated neon purple colors!

  - Code Block Text: Clean monospace font with emerald green/cyan syntax highlighting (#38BDF8 / #34D399), clean dark background (#030712).

Component Styling Upgrades:

1. Category & Filter Pills:
- Inactive pills: Matte dark gray bg (#1E293B), border (#334155), white text.
- Active pill: Glowing sleek cyan border (#00E5FF), deep navy fill (#0F172A), crisp white text.

- Styled like a real modern IDE (VS Code / Cursor style).

3. Inputs (Variáveis Customizáveis):
- Inputs with dark slate background (#1E293B), crisp 1px border (#334155), focus ring in bright electric cyan (#00E5FF). High contrast white text when typing.

4. Buttons:
- Primary CTA buttons ("Entrar na Comunidade", "Carregar Prompt"): High-end solid cyan/blue gradient (#00E5FF to #2563EB) with crisp white/dark text, subtle hover lift effect.

Ensure all elements look cohesive, highly readable, balanced, and state-of-the-art!
```
