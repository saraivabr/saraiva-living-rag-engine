# SexyFlow Zernio — prompts específicos por intenção

## Janela e escopo

- Auditoria em 2026-08-04, com janela móvel das 3 horas encerrada por volta de 17:30 UTC.
- Conta e mídia foram limitadas ao fluxo do Reel de sites (`18130447453725127`).
- Dados de jornada foram agregados sem nome, username, sender ID, message ID ou conteúdo privado.

## Evidência e hipótese

- A Lambda registrou 316 invocações, 0 erros e 0 throttles na janela.
- Entre 41 sessões com entrega histórica do prompt, 33 escolheram `Vender sites` e 8 escolheram `Minha empresa`.
- O fluxo enviava o mesmo prompt aos dois grupos.
- Hipótese: um prompt específico para cada intenção aumenta a utilidade imediata sem adicionar fricção nem mensagens.

## Mudança

- `Minha empresa` recebe um prompt de 888 caracteres voltado a publicar o site do próprio negócio.
- `Vender sites` recebe um prompt de 881 caracteres voltado a apresentar um site demonstrativo a um potencial cliente.
- O segundo prompt proíbe inventar resultados, avaliações, preços e fatos, usando `[VALIDAR COM CLIENTE]` quando necessário.
- A entrega continua com exatamente 2 mensagens após a confirmação do follow: um texto e um card.
- O único link continua sendo o card `VER A BIBLIOTECA`, com rota `/instagram/product`.
- Prompt vazio ou acima de 900 caracteres agora falha fechado, impedindo uma entrega parcial só com oferta.

## Marcos de conversão
